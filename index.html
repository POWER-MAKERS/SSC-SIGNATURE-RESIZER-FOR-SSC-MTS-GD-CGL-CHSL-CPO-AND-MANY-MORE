Frequently Asked Questions

Why is the Choose image button not working?
This version connects both the visible button and the upload area directly to the same file input and also supports drag-and-drop. It does not depend on a hidden third-party cropper.
Does the tool upload my signature to a server?
No. Image processing is performed in your browser using JavaScript and Canvas. The selected image is not sent to this website by this page.
Can I use PNG as the source?
Yes. PNG, WebP and JPEG/JPG can be selected as source files. The generated download is JPEG.
Can I crop the signature on a phone?
Yes. The crop rectangle uses pointer events, so touch dragging works on supported mobile browsers.
Does 10–20 KB mean the image must look physically 10–20 KB?
No. KB is the digital file size. Physical dimensions and pixel dimensions are separate requirements.
Why can a simple signature be smaller than 10 KB?
A very simple image can compress extremely well. JPEG quality cannot always make such an image large enough. This tool can optionally add a JPEG comment segment to meet a minimum byte count without changing the visible pixels.
Will this guarantee SSC acceptance?
No. The tool can verify the technical settings you enter, but SSC may reject a signature for illegibility, blur, miniature appearance or other notice-specific reasons.
Which requirement should I follow if this page and the SSC portal differ?
Follow the active SSC notification and application portal. They are the final authority.
